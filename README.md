# Тюрк-Лого / Türk-Logo

Искусственный язык (конланг), спроектированный как нейтральная лингва-франка для тюркских народов.

## Философия

**Цель:** Узбеку, казаху, турку и татарину должно быть одинаково легко, интуитивно и приятно изучать этот язык. Ни один живой тюркский язык не доминирует — мы ищем пратюркский консенсус.

## Четыре архитектурных принципа

| Принцип | Описание | Аналог |
|---|---|---|
| **Пантюркский консенсус** | Корни выбираются из пратюркских форм, понятных всем 4 целевым языкам | API-контракт для всех клиентов |
| **Модульная агглютинация** | `[КОРЕНЬ] → [МНОЖЕСТВЕННОСТЬ] → [ПРИТЯЖАТЕЛЬНОСТЬ] → [ПАДЕЖ]` | Неизменяемый объект + цепочка трансформаций |
| **Сингармонизм** | Строгая гармония гласных без исключений | Линтер / type checker |
| **Строгий SOV** | Субъект → Объект → Глагол, всегда | Единственный порядок операторов |

## Целевые языки

- Узбекский (O'zbek tili)
- Казахский (Қазақ тілі)
- Турецкий (Türkçe)
- Татарский (Татар теле)
