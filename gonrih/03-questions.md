## Задачи следующей сессии

1. Выбрать корни для каждого вопросительного слова по принципу пантюркского консенсуса
2. Проверить каждый корень через линтер сингармонизма
3. Убедиться, что вопросительные слова не пересекаются с местоимениями
4. Зафиксировать вопросительную частицу (аналог `-mı/-mi` в турецком)
