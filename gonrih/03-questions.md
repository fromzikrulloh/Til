# 03. Вопросительные слова / Question Words

## Два корня — вся система

В пратюркском языке вопросительные слова строились из двух корней:

| Корень | Значение | Тип |
|---|---|---|
| `*ne` | «что» | субстантивный (о вещах и причинах) |
| `*qay` | «который, где» | локативный/квалитативный (о месте, способе, количестве) |

Из этих двух корней + агглютинация = вся вопросительная система Тюрк-Лого.

| Сколько? | **qança** | пратюркск. `*qançā` | qancha | qansha | kaç | niçä |

## Разбор ключевых решений

### `qay` — локативный корень (не `nere`)
Турецкое `nere-` — позднее нововведение, буквально `ne` + `yer` (что + место).
Пратюркская форма — `*qay-`. Узбекское `qayer` = тот же `qay` + `yer`, только аналитически.
В Тюрк-Лого `yer` (место) отдельное слово; `qay-` — чистый вопросительный корень.

### Локативные вопросы = чистая агглютинация
```
qay  +  -DA   →  qayda   (где?)      задний ряд, -da
qay  +  -GA   →  qayga   (куда?)     задний ряд, -ga
qay  +  -DAN  →  qaydan  (откуда?)   задний ряд, -dan
```
Корень неизменен. Меняется только падежный суффикс. Идеальная модульность.

### `qaçan` — «когда?» (не `ne zaman`)
Пратюркская форма `*qaçan` сохранилась в узбекском, казахском и татарском.
Турецкое `ne zaman` — поздняя аналитическая замена. В Тюрк-Лого возвращаем синтетическую форму.

### `nege` — «почему?» = `ne` + дательный падеж
Буквально: «для чего?» / «к чему?».
Казахское `nege` — прямое совпадение. Это прозрачная агглютинативная конструкция:
```
ne  +  -GE  →  nege   (почему? = «для чего?»)   передний ряд, -ge
```

### `qanday` — «как?» и «какой?»
В пратюркском один корень покрывал оба значения (способ и качество).
Контекст разрешает неоднозначность — так же как в казахском и узбекском.

## Вопросительная частица (да/нет вопросы)

Для общих вопросов (без вопросительного слова) — постпозитивная частица `-MI`:

| Последний гласный | Частица |
|---|---|
| a, ı | -mı |
| o, u | -mu |
| e, i | -mi |
| ö, ü | -mü |

```
ol keldi        →  Он пришёл.
ol keldi-mi?    →  Он пришёл?

biz bar-da-mız? →  Мы здесь?   (bar = есть/существует, -da = лок., -mız = 1мн.)
```
