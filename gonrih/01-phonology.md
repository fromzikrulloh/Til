# 01. Фонология / Phonology

## Гласные (Vowels)

Тюрк-Лого использует классическую 8-гласную тюркскую систему. Никаких исключений.

|  | Неогублённые | Огублённые |
|---|---|---|
| **Задний ряд** | **a**, **ı** | **o**, **u** |
| **Передний ряд** | **e**, **i** | **ö**, **ü** |

```
ЗАДНИЙ:   a  ı  o  u
ПЕРЕДНИЙ: e  i  ö  ü
```

## Правила сингармонизма (The Linter)

Сингармонизм — строгий тип-чекер языка. Нет исключений, нет «исторических форм».

### Правило 1 — Рядность

Если последний гласный корня **задний** (`a ı o u`) → все суффиксы берут **задние** гласные.  
Если последний гласный корня **передний** (`e i ö ü`) → все суффиксы берут **передние** гласные.

### Правило 2 — Огублённость

Огублённость суффиксного гласного определяется по таблице:

| Последний гласный корня | Суффиксная переменная A | Суффиксная переменная I |
|---|---|---|
| a | → a | → ı |
| ı | → a | → ı |
| o | → a | → u |
| u | → a | → u |
| e | → e | → i |
| i | → e | → i |
| ö | → e | → ü |
| ü | → e | → ü |

### Правило 3 — Запись суффиксов

Суффиксы в спецификации записываются заглавными буквами-переменными:

| Переменная | Значение |
|---|---|
| `A` | `a` (задний) или `e` (передний) |
| `I` | `ı / u` (задний) или `i / ü` (передний) |

**Пример:**  
Суффикс множественного числа `-LAR/-LER` записывается как `-LAR` (с переменной `A`).

```
köl  (озеро, передний ряд) + -LAR → köl-ler  ✓
kol  (рука,  задний ряд)   + -LAR → kol-lar  ✓
kol  (рука,  задний ряд)   + -LER → ошибка линтера  ✗
```

### Правило 4 — Сцепление

При добавлении нескольких суффиксов каждый следующий суффикс согласуется с **последним гласным предыдущего суффикса**, а не корня.

```
[КОРЕНЬ] + [СУФФИКС₁] + [СУФФИКС₂]
                 ↑             ↑
           смотрит на       смотрит на
            корень         СУФФИКС₁
```
